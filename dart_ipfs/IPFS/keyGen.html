Generates a new Ed25519 key pair stored under name and returns its IPNS name (base36-encoded libp2p-key CID).

type currently only accepts 'ed25519'. Ed25519 keys have a fixed 256-bit size, so size must be null or 256; any other value throws ArgumentError rather than being silently ignored. The node's keystore must be unlocked first. Once stored, name can be passed as keyName to publishIPNS.
