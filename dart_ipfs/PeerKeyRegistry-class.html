PeerKeyRegistry

PeerKeyRegistry class

Registry for caching and verifying bindings between PeerId strings and their corresponding Ed25519 public keys.

In IPFS/libp2p, a peer's identity is derived from its public key (PeerId.fromPublicKey). Because the SHA-256 derivation is one-way, remote public keys must either be supplied alongside signed payloads or discovered via the Identify protocol.

PeerKeyRegistry verifies that any supplied public key cryptographically hashes to the peer ID before storing it, preventing identity spoofing.
