MFSManager

MFSManager class

Manages the Mutable File System (MFS) for an IPFS node.

Every mutation writes its blocks to the block store and persists the new root CID to the datastore (write-through). flush/sync therefore act as barriers that wait for in-flight mutations and re-persist the root — which is also what Kubo's ipfs files flush does when the MFS write buffer is drained.
