BlockStore

BlockStore class

Persistent storage for content-addressed blocks in IPFS.

Platform Note: Storage behavior is platform-dependent. On VM platforms, it uses the local file system. On Web platforms, it uses IndexedDB via the IpfsPlatform abstraction.

Blocks are stored as files named by CID. The block index tracks CIDs only; block data is served from disk through a bounded in-memory LRU cache, so memory use does not grow with repository size.
