# dart_ipfs_quic Example

This example demonstrates how to instantiate and query the pure-Dart `QuicTransport` provided by `dart_ipfs_quic`.

## Features
- Inspecting supported libp2p QUIC multiaddr protocols (`/ip4/udp/quic-v1`, `/ip6/udp/quic-v1`).
- Validating listen and dial address support.
- Clean lifecycle shutdown.

## Running the Example

```bash
dart run example/main.dart
```
